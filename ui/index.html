    How ALO uses these readings

    Latency maps to a network profile: under 30 ms = fast wired/Wi-Fi, 30–200 ms = 4G-like, over 200 ms = 3G-like. That profile and the page's size feed the model. CPU, memory and battery are displayed now and are the next inputs to add once the collector records them.
